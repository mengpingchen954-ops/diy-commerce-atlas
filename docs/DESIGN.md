# 设计与内容约定

本网站是资料工具，不是已上线的交易 SaaS。用户授权整理全部对话资料、图片参考并发布 GitHub。独立目录与仓库，不混入其他游戏。

设计定位：面向项目发起人和潜在商家的中文知识工作台，采用清晰、克制的编辑式界面。DESIGN_VARIANCE 5 / MOTION_INTENSITY 2 / VISUAL_DENSITY 5。使用 React + Vite，原生 CSS，Phosphor 图标。

视觉：白色侧栏，浅灰绿背景 #f5f7f5，墨色正文 #192b24，统一绿色重点 #185c48。页面宽 1440 下固定 236px 目录，内容最大 1120px。主标题 38px、正文 15px、行高 1.8；界面用系统中文字体，无远程字体。圆角 12/20px，轻分隔，无装饰性渐变。移动端目录可开合，表格独立横向滚动。

首屏文字：品牌“手作生意图谱”，标题“把手作灵感，变成可经营的生意。”，说明“游戏化 DIY 的品类、玩法与商业路径，都在这里。”，操作“探索品类地图”和“查看落地路线”。九个目录：项目总览、品类地图、玩法机制、商业模式、商家与服务、产品引擎、案例与截图、落地路线、研究备忘。全局搜索、收藏、品类详情是核心交互。

图像生成工具当前未提供，未使用付费 API 替代，也没有生成或声称存在已获用户审批的概念图。以本设计约定和用户提供的参考截图作为实现依据。主视觉为真实截图裁切，概念流程以 HTML/CSS 表达。实际页面截图用于桌面和移动检查。

资料标记：用户设想、产品建议、截图可见、文案声明、待核验、定价草案。不得把竞品印象、市场热度、平台规则或供应商工艺写成已验证事实。先前相互矛盾的优先级作为不同路线保留。

图片仅使用用户提供的十张参考截图，去除重复购物车图后展示九张；公开副本遮盖联系手机号、访客编号及支付金额。它们属于第三方产品界面参考，不代表本站品牌或实现。未发布原始未脱敏截图。
