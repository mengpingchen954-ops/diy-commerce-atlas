# 手作生意图谱

[打开网站](https://mengpingchen954-ops.github.io/diy-commerce-atlas/) · [验收记录](docs/QA.md)

中文游戏化DIY商业研究资料库。根据用户在本次对话提供的文本、粘贴附件和好运成串参考截图整理，合并重复内容，保留具体品类、玩法、收费草案、商家服务、产品能力与验证边界。

网站是可浏览的资料工具，不是实际支付、抽奖或多商家交易系统。

## 使用

- 20个品类组，可按商品名称、分组、履约方式筛选。
- 品类详情提供具体项目、互动方式、商家、履约、最小验证方案和制作边界。
- 品类页提供12种休闲手作灵感，以及串珠、奶油胶、拼豆、滴胶、黏土五个饰品游戏方向的制作循环与适配建议；相关品类详情、搜索与Markdown下载同步收录。选题建议不代表实时热度排行。
- 全站搜索覆盖品类、玩法、商业、商家、引擎、截图、路线与研究备忘。
- 自营定制专题：T恤采购与加工、生日／婚宴礼盒选品、包装外协、自行组装发货，以及设备、订单成本和小批量试单建议；首页及商业、品类、路线页有对应入口或说明。
- 收藏保存在访客浏览器本地，不上传到服务器。
- 支持下载完整Markdown资料。
- 9张脱敏参考图，支持放大阅读；两张重复购物车图归并。
- 哈希路由适配GitHub Pages仓库子目录，手机与桌面均可用。

## 开发与构建

需要Node.js 22.12及以上。

```sh
npm ci
npm test
npm run dev
npm run build
node tests/public.mjs
```

内容在 `src/content.js`，页面组件在 `src/Pages.jsx`。构建先由 `scripts/export.mjs` 生成 `public/资料总集.md`，再由Vite构建到 `dist`。更新内容后重新构建，下载文件与网站同步。

## 发布

GitHub Actions使用官方Pages流程：安装依赖、内容测试、生产构建、上传静态产物、部署。仓库启用GitHub Pages的Actions来源后，推送main自动更新。

## 来源、证据与隐私

“截图可见”只证明界面或文案出现，“文案声明”不代表实际行为已核验。市场热度、竞品现状、平台当期规则及供应商工艺均没有在本资料中做外部核验。99／199／399元仅是定价草案。各品类的实现难度与顺序为产品建议。

截图中的手机号、访客编号和支付金额已遮盖。未提交未脱敏的原始附件、凭据、其他项目、个人文件、浏览器数据、缓存或测试截图。第三方产品图仅作研究参考，相关品牌和界面属于各自权利方，本站与它们无关联或背书。截图不是本站自身功能演示，也不是本站隐私政策。

本站仅使用静态资源；没有统计脚本、远程字体或运行时外部API。GitHub Pages自身的服务数据处理以其政策为准。
